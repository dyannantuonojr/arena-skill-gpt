# Arena GPT Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish a tested 16-competitor GPT/Codex fork retaining upstream history.
**Architecture:** Keep the Python state machine and prompt templates; port the
runtime orchestration instructions and add strict verdict validation.
**Tech Stack:** Python 3.8+ standard library; GitHub Actions; Archify HTML.
**Spec:** ../specs/2026-10-24-arena-gpt-design.md

## Global Constraints

- Default and maximum CLI competitors: 16. Wave default: 1.
- Preserve MIT credit, independent judges, .arena state, and project isolation.
- No API dependency or invented capability claims.

## Review Focus

- Invalid counts/waves must fail cleanly before filesystem writes.
- Incomplete, non-finite, out-of-range scores must not advance competitors.
- Fatal markers must be explicit booleans, including in final comparisons.
- Interrupted jobs must remain discoverable; invalid judges must be rescheduled.
- Worker contexts must be independent and bounded by the runtime's capacity.
