# Direct Arena UI

Start Arena submits the task and rubric inside the loopback app. The Python
coordinator freezes inputs and executes separate signed-in Codex CLI sessions for
16 draft, 15 judge, and 2 required package jobs, at most three concurrently.
Codex manages account authentication; Arena never reads or stores tokens. User
model configuration is inherited. Workers cannot spawn more agents, and retain
workspace-write permissions. Task text never becomes a shell command.

Only generated reports and diagram copies are served. Host, Origin, and nonce
checks protect mutations; binding is loopback-only. Progress, cancellation,
failures, tree reading, and finalist guides stay in the app. The copied-prompt
handoff is removed. Offline reports remain readable without execution controls.
A Start click authorizes the described jobs. The user supplies the real question.

Verification includes synthetic-worker orchestration explicitly labeled as such,
HTTP safety tests, real signed-in CLI probes including actual file output, native
browser gates, and browser UI checks. Never invent model results or receipts.
